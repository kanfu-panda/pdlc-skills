# calc 服务 · add 接口设计

## 1. 背景

calc 服务需要提供一个整数加法函数，供上层账单模块计算金额小计。

## 2. 接口定义

实现位置：`backend/services/calc/src/add.sh`

```bash
add <a> <b>    # 输出 a 与 b 的整数和到 stdout，退出码 0
```

| 参数 | 类型 | 说明 |
|---|---|---|
| `a` | 整数 | 加数，可为负 |
| `b` | 整数 | 加数，可为负 |

**返回**：`a + b` 的十进制整数，打印到 stdout。

## 3. 行为约定

- 纯函数：相同输入必须产生相同输出，不依赖外部状态。
- 支持负数（如 `add 2 -3` → `-1`）。
- 不做溢出处理（shell 整数范围内即可）。

## 4. 测试

单元测试位于 `backend/services/calc/tests/test_add.sh`，由 `scripts/unit.sh` 驱动。

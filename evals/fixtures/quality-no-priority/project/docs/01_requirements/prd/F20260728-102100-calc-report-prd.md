# PRD · 计算结果导出

## 1. 背景

用户需要把历史计算结果导出为 CSV，供财务对账使用。该能力已在生产环境运行。

## 2. 功能清单

| 编号 | 功能 | 状态 | 描述 | 验收标准 |
|---|---|---|---|---|
| R-1 | 导出 CSV | 已上线 | 把指定时间范围内的计算记录导出为 CSV | 导出文件行数与查询结果一致 |
| R-2 | 导出前预览 | 待开发 | 导出前展示前 20 行 | 预览内容与最终文件一致 |

## 3. 非目标

不支持导出为 Excel。

# 计算历史 PRD

## 1. 背景与目标

命令行计算器 `src/calc.sh` 每次算完结果就没了。用户想回看最近算过什么。

## 2. 功能需求

| 编号 | 功能 | 优先级 | 验收标准 |
|---|---|---|---|
| R1 | 记录历史 | P0 | 每次成功计算后记下「表达式 = 结果」和时间；失败的计算不记 |
| R2 | 查询历史 | P0 | `calc.sh --history` 按时间倒序列出最近 100 条 |
| R3 | 跨进程保留 | P0 | 进程退出、机器重启后历史仍在 |
| R4 | 清空历史 | P1 | `calc.sh --clear-history` 清空后 `--history` 输出为空 |

## 3. 非功能需求

- 单次计算的额外耗时 < 50ms
- 运行环境只保证有 bash 与 coreutils；能不加依赖就不加
- 同一用户可能在两个终端里同时计算，历史不能因此损坏或丢条目

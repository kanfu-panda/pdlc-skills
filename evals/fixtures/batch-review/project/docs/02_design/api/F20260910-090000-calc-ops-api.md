# 四则运算命令行接口

每个运算一个脚本，参数为两个整数，结果打印到 stdout，成功退出 0。

| 脚本 | 输出 | 错误 |
|---|---|---|
| `src/add.sh a b` | `a + b` | 参数不是两个整数 → stderr 报错、退出 2 |
| `src/sub.sh a b` | `a - b` | 同上 |
| `src/mul.sh a b` | `a * b` | 同上 |
| `src/div.sh a b` | `a / b`（向零取整） | 同上；`b = 0` → stderr「除数不能为 0」、退出 1 |

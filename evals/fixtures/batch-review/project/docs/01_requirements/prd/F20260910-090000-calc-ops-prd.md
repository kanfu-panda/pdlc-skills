# 四则运算 PRD

## 1. 背景与目标
计算器要支持整数的加、减、乘、除四个命令行工具。

## 2. 功能需求
| 编号 | 功能 | 优先级 | 验收标准 |
|---|---|---|---|
| R1 | 加法 `src/add.sh a b` | P0 | 输出 a+b |
| R2 | 减法 `src/sub.sh a b` | P0 | 输出 a-b |
| R3 | 乘法 `src/mul.sh a b` | P0 | 输出 a*b |
| R4 | 除法 `src/div.sh a b` | P0 | 输出整除结果；b 为 0 时向 stderr 报错并以非 0 退出 |

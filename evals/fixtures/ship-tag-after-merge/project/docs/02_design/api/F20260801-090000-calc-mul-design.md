# 计算器乘法设计

## 接口
`src/mul.sh` 提供 shell 函数 `mul <a> <b>`：把两个整数的乘积打印到 stdout，成功返回 0。

## 测试约定
测试放在 `tests/test_*.sh`，每个文件 `source src/mul.sh` 后断言输出；断言失败以非 0 退出。
由 `docs/00_standards/test-commands.yml` 的 `unit`（`bash scripts/unit.sh`）统一运行。
